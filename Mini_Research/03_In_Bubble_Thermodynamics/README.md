Автор: **Dimitri Bolt**. Academic supervisor: **Prof. Dr. Ildar R. Gabitov**.

Англоязычный научный отчёт: [report/main.pdf](report/main.pdf),
исходник: [report/main.tex](report/main.tex). Основные значения температур:
[results/main_temperature_comparison.csv](results/main_temperature_comparison.csv).

Здесь впервые в серии рассчитаны временные зависимости температуры и её максимумы.
Используются принятые механические результаты MR2, без повторного расчёта старого
механического перебора и без изменения MR1/MR2. Адиабатическая модель A дополняется
моделью B со знакопеременным теплообменом: сначала **one-way post-processing**, затем
связанная система Keller--Miksis + энергия. Источник тепла равен нулю и вынесен
в отдельный модуль. Лазер, наночастицы, реакции, ионизация и Mini-Research 4 не реализованы.

## Входы и смысл результатов

Принятый механический snapshot: `f1f3e812d77fd7fa058ce111ff484b1c8658f937`.
Исторический исходный MR1: `d59bc0d0119b514152f763e2537a0477c7c63663`.
Нужны соседние папки `../01_Bubble_Dynamics`, `../02_Compressible_Bubble_Dynamics`,
общий `../../Plasma-plan.tex` и три названных PDF в `../../Library`.
Все отслеживаемые входы сверяются с принятым snapshot и хешируются.
Большие исходные траектории не копируются в MR3.

Для KM сохранены категории: 1.0 bar — `conditional_baseline`, 1.15 bar —
`conditional_sensitivity`, 1.3 bar — `formal_extreme_scenario`. Все значения остаются
условными оценками модели. Экстремальные RP решения диагностические, даже если
интегратор завершил пять циклов. Семь неполных RP траекторий сохраняют только
наблюдаемый интервал; глобальный пятицикловый максимум у них не определён.

Умеренный теплообмен может **повысить** максимум по сравнению с полностью
адиабатическим циклом: при расширении газ получает тепло от жидкости. Обратная
связь давления меняет саму механику. Поэтому one-way и связанный расчёт нельзя
смешивать. При изменении gamma в модели A механика остаётся фиксированной, что
явно отмечено как условная чувствительность, а не новое связанное решение.

Теплопроводности воздуха и аргона взяты из таблицы NIST при **300 K** и далее
считаются постоянными. Это не достоверные свойства газа при экстремальных T.
Модель однородного идеального газа не описывает паровую энергию, скрытую теплоту,
пространственные градиенты и химию. Высокая T не доказывает плазму или синтез.

## Воспроизведение

Производственная среда: Python 3.14, версии сохранены в метаданных. Независимая
проверка использует Python 3.12 и полный `requirements-lock.txt` из чистого окружения.
Для PDF нужны системные `latexmk`, `pdflatex`, пакеты lmodern, amsmath, amssymb,
booktabs, graphicx, array, caption, float, microtype, hyperref; для просмотра — Poppler.
Автоматические тесты используют стандартный `unittest`, без дополнительной зависимости.

Из корня репозитория:

```bash
cd Mini_Research/03_In_Bubble_Thermodynamics
sha256sum -c SHA256SUMS
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-lock.txt
python -m pip check
python -m src.run_experiments --force
python -m src.validate
python -m src.plot_results
python -m unittest discover -s tests -v > results/tests.txt 2>&1
latexmk -pdf -interaction=nonstopmode -halt-on-error -cd report/main.tex
python -m src.package
```

Без `--force` корректные сохранённые тепловые расчёты используются повторно;
после изменения уравнений или настроек необходимо использовать `--force`.
Стадии запускаются отдельно: `--stage audit`, `adiabatic`, `thermal`, `metadata`.
`src.validate` делает дополнительные ограниченные расчёты для проверки сходимости,
а не повторяет старый механический перебор. Для перестройки только рисунков и
таблиц: `python -m src.plot_results`, затем сборка PDF. Новые рисунки — JPG,
300 dpi, на английском, с белым фоном для печати. Промежуточные страницы для
визуальной проверки и служебные файлы LaTeX не входят в публикацию.

Повторные запуски могут изменить время выполнения, двоичные метаданные PDF,
сжатие NPZ и контрольные суммы, сохраняя численные значения в пределах проверенной
точности. Перед перезапуском можно сверить опубликованный комплект по SHA256SUMS.

Первое сильное схлопывание, независимо выбранный минимум цикла и глобальный
минимум — разные события. Максимум модели B ищется по температуре. Новая
интерполяция сохранённых R/U не объявляется исходным непрерывным решением:
скорость между узлами равна производной Hermite-радиуса, ошибку проверяют
на прореженных/принятых сетках. Чтение CSV использует `float_precision='round_trip'`,
чтобы не терять время узких формальных RP пиков.

Погрешности интегрирования, интерполяции и физических предположений различаются.
Небольшой газовый энергетический остаток не означает сохранение полной энергии
газа, пара и жидкости. Сходимость не подтверждает экспериментальную достижимость.
