# Проверка полноты публикации и воспроизводимости

Инструкция и журнал для Dimitri Bolt. Научный отчёт, таблицы и рисунки оформлены на английском языке для Prof. Dr. Ildar R. Gabitov. Статус закрытия этапа в научный отчёт не включён.

## Причина неполной предыдущей публикации

Коммит `799ceaa8e4a1c433c5451838d67e9669bc858bb7` содержал только README.md, report/mini_research_01.tex и report/mini_research_01.pdf. Остальные материалы находились локально и оставались неотслеживаемыми. `git check-ignore -v` не выявил правил, исключающих код, тесты, зависимости, CSV, JSON или рисунки. Следовательно, комплект не был полностью добавлен в индекс предыдущего коммита; это не ошибка генерации файлов.

## Независимый прогон

Проверка выполнена в отдельной папке из архива подготовленного индекса Git. Вместе с папкой исследования извлечены только три необходимые исходные зависимости: две публикации из Library и Plasma-plan.tex. Создано новое изолированное окружение Python 3.12.14; зависимости установлены по requirements-lock.txt, `pip check` пройден.

Выполнены расчёт всех шести амплитуд на пяти периодах, обе серии сходимости, построение девяти рисунков, тесты и сборка LaTeX. В архивной копии нет каталога .git, поэтому поле source_repository_commit в JSON имеет значение null; происхождение исходных документов и кода фиксируется их SHA256. Версия репозитория до дополнения указана выше.

Математическая модель не изменена. SHA256 src/bubble_dynamics.py: `f8c1baaf5a4fc891383b7203b67c026908f4bf005d5418e273b640784e161188`.

Четыре прежних численных CSV (траектории, амплитудная сводка, экстремумы и линейное сравнение) совпали с первоначальным расчётом после нормализации переводов строк. CSV теперь записываются с LF; локальный .gitattributes закрепляет этот формат, чтобы контрольные суммы совпадали в клонах Git.

Помимо исходных проверок добавлены независимое сравнение методов при 1.0 bar, сверка экстремумов CSV со сводкой, проверка обеих серий сходимости и полноты английских исходников отчёта. Все интегрирования завершили пять периодов; технический порог радиуса не достигнут. Относительная ошибка равновесного радиуса равна 0 в машинном представлении.

## Отчёт и согласованность материалов

- PDF собран командой latexmk из исходного LaTeX в чистой копии; 10 страниц: 6 основного текста, 1 библиографии, 3 приложений.
- Все страницы визуально просмотрены. Обрезаний, пустых страниц и нечитаемых формул не обнаружено; предупреждений LaTeX нет.
- Все четыре зависимости input и девять includegraphics существуют; для каждого рисунка присутствуют PDF и PNG.
- В отчёте, подключаемых таблицах и текстах PDF-рисунков отсутствует кириллица. Служебные формулировки о состоянии внутреннего процесса удалены.
- Числа в обеих таблицах сходимости проверены по CSV с учётом округления. Рисунки заново построены только из сохранённых данных.
- Контрольные суммы исходных документов и Python-кода соответствуют run_metadata.json. Исходные публикации и общий план не изменены.
- Итоговый комплект содержит 43 файла. .venv, кэши и промежуточные файлы LaTeX в индекс не включены.

Полный перечень находится в FILE_LIST.txt, контрольные суммы всех остальных файлов — в SHA256SUMS. Перед коммитом комплект повторно извлекается из итогового дерева Git для проверки контрольных сумм, тестов сохранённых артефактов и сборки PDF.
